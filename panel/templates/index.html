Titles{{ hint_button('titleSourceHint', 'titles') }}
Each new film and image set gets a short descriptive title from its prompt; its files are named by it too. With titles enabled, a local model selected for generation or used in the prompt editor also supplies the title. Without one, the choice below applies. Gemini uses one call per run; if it rejects the prompt, the local model titles it instead. Gemini, the local model for private runs asks Gemini only for what isn't made in Private mode, so private prompts never leave the PC for titling. Local model only never sends a prompt to Gemini. Either way the local model first frees ComfyUI's models and takes a little longer. If every one asked fails, it keeps its usual title.
